# Mtag

ブラウザで動作する2D物理模型エディタ。
ブロック、ジョイント、モーターを組み合わせてオリジナルの模型を作成し、物理シミュレーションで動かして遊べます。

## Features
- ブロック配置
- 固定ジョイント
- ヒンジジョイント
- モーター
- 物理シミュレーション
- 2D
- JSON保存/読込
- PC・スマホ対応
